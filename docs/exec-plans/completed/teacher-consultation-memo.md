# 실행 계획: 담당 선생님 상담 메모

## 1. 목표

담당 선생님이 자신이 담당하는 학생의 상담 메모를 조회/작성/수정하고, 학원이 같은 학생 상담 이력에서 선생님 작성 메모까지 확인할 수 있게 한다.

## 2. 배경

현재 상담 요청과 학원 상담 예약 관리는 있으나, 재원생 상담 기록을 학원과 선생님이 함께 남기는 구조가 없다. 상담 기록은 학생 상세 상담 탭에 통합되어야 하며 부모/학생에게 내부 메모 원문은 노출하지 않는다.

## 3. 작업 범위

포함되는 작업:

- `ConsultationMemo` 엔티티와 저장소 추가
- ACADEMY/TEACHER 상담 메모 API 추가
- 담당 수업의 활성 학생 기준 TEACHER 권한 검증
- 학원 학생 상세와 전체 상담 화면의 메모 표시/작성 UI
- 선생님 상담 관리 화면 추가

포함하지 않는 작업:

- 비회원 신규생 상담
- 공개 상담 예약 API
- 청구/수납
- 출석 기능
- 사이드바 상담 메뉴 추가

## 5. 구현 순서

1. 백엔드 상담 메모 도메인, DTO, 저장소, 서비스, 컨트롤러를 추가한다.
2. 상담 요청 연결 및 ACADEMY/TEACHER 권한 검증 테스트를 추가한다.
3. 프론트 타입/API 함수를 추가한다.
4. 선생님 상담 관리 화면과 라우트를 추가한다.
5. 학원 학생 상세 상담 탭과 전체 상담 모달에 메모 표시/작성 UI를 연결한다.

## 6. 검증 방법

- `./gradlew test`
- `npm run lint`
- `npm run build`

## 7. 위험 요소

- 담당 학생 판정이 수업 상태와 수강 상태를 모두 고려하지 않으면 권한 누수가 생길 수 있다.
- 상담 요청과 메모의 학생/학원 불일치를 허용하면 다른 학생 기록에 잘못 연결될 수 있다.

## 8. 롤백 방법

상담 메모 관련 신규 파일과 API/UI 연결 변경을 되돌린다. 기존 상담 요청 API는 유지하므로 롤백 시 기존 예약 흐름은 보존된다.

## 9. 완료 기준

- [x] 선생님은 담당 학생 상담 메모만 조회/작성할 수 있다.
- [x] 학원은 자기 학원 학생의 모든 상담 메모를 조회/작성할 수 있다.
- [x] 선생님 작성 메모와 학원 작성 메모가 학생 상담 탭에 함께 표시된다.
- [x] 상담 요청 연결 시 학원/학생 소유권이 검증된다.
- [x] 필수 테스트와 빌드 검증을 통과한다.
