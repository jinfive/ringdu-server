# Product Overview

## 1. 서비스 방향

Ringdu는 학원, 선생, 학생, 부모를 연결하는 무료 학원 관리 웹/앱 서비스다.

기본 학원 관리 기능은 무료로 제공한다. 운영 규모가 커지거나 자동화가 필요한 경우 다음 기능을 유료화 또는 충전형 기능으로 확장할 수 있다.

```txt
카카오 알림톡 초과 발송
청구서 자동 발송
미납 자동 리마인드
고급 통계
학원 광고
프리미엄 커뮤니티 노출
추후 구독형 기능
```

## 2. MVP 역할 구조

MVP 역할은 다음 5개를 기준으로 한다.

```txt
ACADEMY
TEACHER
STUDENT
PARENT
ADMIN
```

한국어 표현은 다음 기준을 사용한다.

| Role | 표현 |
|---|---|
| ACADEMY | 학원 |
| TEACHER | 선생 |
| STUDENT | 학생 |
| PARENT | 부모 |
| ADMIN | 플랫폼 관리자 |

`OWNER`, `DESK`는 MVP 핵심 역할에서 제외한다. 초기에는 `ACADEMY` 계정이 원장, 데스크, 운영자 역할을 통합해서 담당한다. `OWNER`, `DESK`는 향후 학원 내부 세부 권한 분리가 필요할 때 확장 역할로 검토한다.

선생 등록

클래스 생성

기본 숙제 등록
```

```

## 5. 개발 우선순위

현재 인증/인가 기본 구조, 프론트 role guard, 학원 가입 신청/승인, Academy 도메인 기본 조회/수정 흐름이 진행된 상태다. 다음 개발 작업은 학원과 선생/학생/부모를 연결하는 소속 구조 구현이다.

```txt
1. Role 구조 정리
2. 학원 도메인
3. 선생/학생/부모 연결 구조
4. 클래스/수업 도메인
5. 출석 도메인
6. 학생 관리
7. 상담 관리
8. 숙제 도메인
9. 청구서/수납
10. 커뮤니티
11. 광고
12. 알림/유료화
```

현재 작업 브랜치:

```txt
feat/academy-domain
```
