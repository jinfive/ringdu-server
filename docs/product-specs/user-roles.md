# User Roles

## 1. 목적

이 문서는 Ringdu MVP의 사용자 역할과 역할별 기능 범위를 정의한다.

## 2. MVP 역할

Ringdu MVP는 다음 역할을 사용한다.

| Role | 한국어 표현 | 설명 |
|---|---|---|
| ACADEMY | 학원 | 학원 운영 전체를 관리하는 계정 |
| TEACHER | 선생 | 담당 수업과 학생을 관리하는 계정 |
| STUDENT | 학생 | 본인 수업과 학습 정보를 확인하는 계정 |
| PARENT | 부모 | 자녀의 학원 생활 정보를 확인하는 계정 |
| ADMIN | 플랫폼 관리자 | Ringdu 플랫폼을 운영하는 계정 |

`OWNER`, `DESK`는 MVP에서 제외한다. 초기에는 `ACADEMY`가 원장, 데스크, 운영자 역할을 통합해서 담당한다. 학원 내부 조직이 복잡해지는 시점에 세부 권한으로 확장할 수 있다.

## 3. ACADEMY / 학원

학원 계정은 학원 운영 전체를 관리한다.

```txt
학원 정보 관리
선생 등록/초대
학생 등록/관리
부모-학생 연결 관리
클래스/수업 관리
시간표 관리
출석 관리
숙제 관리
공지 관리
청구서/수납 관리
학생 상담 기록 관리
```

## 4. TEACHER / 선생

선생은 본인이 담당하는 수업과 학생을 관리한다.

```txt
담당 클래스 조회
담당 학생 조회
출석 요청 승인/반려
숙제 등록
수업 자료 공유
공지 작성
학생 상담 기록 작성
학부모 상담 내용 기록
```

## 5. STUDENT / 학생

학생은 본인의 수업과 학습 정보를 확인하고 출석 요청을 한다.

```txt
내 클래스 조회
내 시간표 조회
출석 요청
내 출석 기록 조회
숙제 확인
학생 커뮤니티 이용
```

## 6. PARENT / 부모

부모는 자녀의 학원 생활 정보를 확인한다.

```txt
자녀 등록 요청
자녀 출석 조회
자녀 시간표 조회
자녀 숙제 확인
청구서/수납 상태 확인
공개된 상담 내용 확인
학부모 커뮤니티 이용
```

## 7. ADMIN / 플랫폼 관리자

ADMIN은 학원 내부 관리자가 아니라 Ringdu 플랫폼 운영자다.

```txt
전체 학원 관리
전체 사용자 관리
커뮤니티 신고 관리
광고 관리
서비스 공지 관리
유료 기능/충전 관리
운영 로그 확인
```

## 8. 일반 회원가입 기준

MVP 일반 회원가입은 다음 역할만 허용한다.

```txt
TEACHER
PARENT
STUDENT
```

`ADMIN`은 일반 회원가입으로 생성하지 않는다. `ACADEMY`는 일반 회원가입으로 즉시 활성 계정이 되지 않고, 별도 학원 가입 신청을 통해 승인 대기 계정으로 생성한다.

```txt
ADMIN
- 최초 계정은 개발/운영자가 생성한다.
- local/dev 기본 계정은 admin@ringdu.com 이다.
- local/dev 기본 비밀번호는 ringdu1234 이며 DB에는 BCrypt 해시로 저장한다.
- 운영 환경에서는 기본 비밀번호를 그대로 사용하면 안 되며, 환경변수 또는 별도 생성 절차로 대체한다.

ACADEMY
- 비로그인 사용자가 학원 가입 신청을 제출할 수 있다.
- 가입 직후 `PENDING_APPROVAL` 상태이며 로그인할 수 없다.
- ADMIN 승인 후 `ACTIVE` 상태가 되면 로그인할 수 있다.
- ADMIN 승인 시 신청서 정보를 기반으로 `Academy` 데이터가 생성되고, `ACADEMY` 사용자와 1:1로 연결된다.
- 승인된 `ACADEMY`는 `/api/academies/me`로 자기 학원 정보를 조회/수정하고 `/api/academies/me/dashboard`로 운영 요약을 조회한다.
- 승인된 `ACADEMY`는 선생님 이메일/전화번호로 초대장을 생성하고, 보낸 초대장과 소속 선생님 목록을 조회할 수 있다.
- ADMIN이 학원 계정을 직접 생성하는 API는 운영 예외 기능으로 유지할 수 있다.
- 출석 승인은 선생 역할의 책임이며, 학원 계정은 출석 현황 조회만 담당한다.

TEACHER
- 선생님은 학원이 보낸 초대장을 Ringdu 웹/앱에서 확인한다.
- 선생님은 자기 이메일로 온 초대장만 수락 또는 거절할 수 있다.
- 수락하면 `AcademyMember`로 학원 소속 선생님 관계가 생성된다.
- 초대코드를 직접 입력하는 방식은 사용하지 않는다.
```
