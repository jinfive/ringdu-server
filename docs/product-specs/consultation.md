# 상담 예약

## 1. 목적

재원생 학부모가 학원 대표 계정 또는 자녀의 담당 선생님과 상담 가능한 시간을 확인하고 상담을 요청할 수 있게 한다.

## 2. 사용자

- `ACADEMY`: 학원 대표 및 학원 소속 선생님의 상담 가능 시간 관리
- `TEACHER`: 본인의 학원별 상담 가능 시간 관리
- `PARENT`: 연결된 자녀의 학원 대표 또는 담당 선생님 선택 및 상담 요청

## 3. 요구사항

- 상담 담당자는 `ACADEMY_ACCOUNT` 또는 `TEACHER`다.
- 학원 대표 상담은 `teacherUserId = null`, 선생님 상담은 해당 사용자 ID로 구분한다.
- 상담 가능 시간은 `academyId + consultantType + teacherUserId` 기준으로 관리한다.
- 같은 선생님의 같은 요일 활성 시간은 겹칠 수 없다.
- 학부모는 자녀가 활성 수강 중인 수업의 활성 선생님만 선택할 수 있다.
- `REQUESTED`, `APPROVED` 상담 요청은 겹치는 시간을 점유한다.
- `REJECTED`, `COMPLETED`, `CANCELED` 요청은 시간을 점유하지 않는다.
- 상담 요청 생성 시 조회 결과를 신뢰하지 않고 서버가 가능 시간과 중복 예약을 다시 검증한다.
- 선생님 활성 요청 목록에는 본인에게 배정된 `REQUESTED`, `APPROVED`만 표시한다.
- 학원 활성 요청 목록에는 `REQUESTED`, `APPROVED`만 표시하고 종료 상태는 학생 상담 이력에서 확인한다.

## 4. 기본 흐름

1. 학원은 학원 대표 또는 선생님별 상담 가능 시간을 등록하고, 선생님은 본인 시간을 등록한다.
2. 학부모가 자녀와 학원을 선택한다.
3. 학원 상담 또는 수강 중인 수업의 담당 선생님을 선택한다.
4. 선택한 월의 가능한 날짜와 시간대를 조회한다.
5. 비어 있는 시간과 상담 내용을 선택해 요청한다.

## 5. 예외 상황

- 학원 소속이 아닌 선생님 슬롯 생성
- 다른 선생님 슬롯 수정 또는 삭제
- 겹치는 활성 가능 시간 생성
- 담당하지 않는 선생님으로 상담 요청
- 가능 시간 밖의 상담 요청
- 이미 점유된 시간과 겹치는 상담 요청

## 6. 권한

- 학원은 자기 학원의 대표 상담과 활성 선생님 슬롯을 관리한다.
- 선생님은 본인이 활성 연결된 학원의 본인 슬롯만 관리한다.
- 학부모는 활성 관계로 연결된 자녀의 담당 선생님과 시간만 조회하고 요청한다.

## 7. 데이터

- 상담 가능 시간: 학원, 담당자 유형, 선생님(nullable), 요일, 시작/종료 시간, 상담 유형, 상태
- 상담 요청: 학원, 학생, 학부모, 담당자 유형, 선생님(nullable), 요청 날짜/시간, 주제, 상태

## 8. 완료 기준

- [ ] 역할별 관리 API와 화면이 동작한다.
- [ ] 월별 예약 가능 슬롯과 점유 사유가 표시된다.
- [ ] 예약 중복이 명확한 비즈니스 예외로 차단된다.
- [ ] 신규생 공개 상담은 노출하지 않는다.
