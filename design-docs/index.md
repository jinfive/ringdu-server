# Ringdu Design Docs Index

Ringdu 백엔드 설계 문서 색인이다. 아직 작성되지 않은 세부 문서는 링크하지 않고 상태만 표시한다.

| 문서 | 상태 | 내용 |
|---|---|---|
| 인증 설계 | Planned | Login/JWT, Refresh Token Cookie, rotation, Redis 전환 |
| 권한 설계 | Planned | ADMIN/OWNER/DESK/TEACHER/PARENT/STUDENT 권한 검증 |
| 학원/회원 관계 설계 | Planned | Academy, AcademyMember, StudentGuardian, AcademyStudent |
| 출석 설계 | Planned | 반별 출석 체크, 학생/학부모 조회, 상태 변경 이력 |
| 숙제 설계 | Planned | 담당 반 숙제 등록, 학생 제출, 학부모 조회 |
| 청구서/납부 설계 | Planned | 학생 기준 청구서, 납부 상태, 미납 조회 |
| 공지 설계 | Planned | 학원 공지, 역할별 조회/작성 권한 |

현재 공통 설계 기준은 루트 [DESIGN.md](../DESIGN.md), 보안 기준은 [SECURITY.md](../SECURITY.md), 개발 계획은 [PLANS.md](../PLANS.md)를 따른다.
