# Ringdu Product Specs Index

Ringdu 제품 명세 색인이다. 현재 저장소는 백엔드 API 구현을 기준으로 상태를 관리한다.

| 영역 | 상태 | 범위 |
|---|---|---|
| Health Check | Done | `/api/health` |
| Common Foundation | Done | 공통 응답, 예외, BaseEntity, Role |
| Auth | In Progress | signup 완료, login/JWT/refresh/logout/me 작업 중 |
| User | In Progress | 로그인 계정 Entity, provider 확장 구조 |
| Academy | Planned | 학원 정보 관리 |
| AcademyMember | Planned | OWNER/DESK/TEACHER와 학원 관계 |
| Student | Planned | 학생 프로필 |
| StudentGuardian | Planned | 학부모-학생 관계 |
| AcademyStudent | Planned | 학원-학생 관계 |
| Class | Planned | 반 관리 |
| Schedule | Planned | 시간표 관리 |
| Attendance | Planned | 출석 체크와 이력 조회 |
| Homework | Planned | 숙제 등록, 조회, 제출 |
| Invoice/Payment | Planned | 청구서와 납부 상태 |
| Notice | Planned | 학원 공지 |
| Community | Planned | 커뮤니티/홍보 기능 |

세부 스펙 문서는 기능 구현 이슈 단위로 추가한다. 아직 존재하지 않는 세부 문서는 링크하지 않는다.
